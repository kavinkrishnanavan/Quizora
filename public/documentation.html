How to Master Quiz-Wiz?

Quick instructions for teachers to generate worksheets, host quizzes, mark worksheets, and create notes.

Personalized Tests

Generate individualized worksheets for each student from a CSV/Excel list.

Steps

  • Open Personalized.
  • Fill in all parameters.
  • Upload a student list using the CSV/Excel upload.
  • Upload learning materials (optional).
  • Make special requests (optional).
  • Click Generate Worksheets.

Hosting (optional)

  • Sign in () to enable hosted quizzes.
  • After generation, use Host Quiz for All to create links/codes for students.
  • Students open the provided link and submit answers.

Baseline Test

Create a baseline assessment where students enter their name and answer on their own.

Steps

  • Open Baseline.
  • Fill in all parameters.
  • Upload learning materials (optional).
  • Make special requests (optional).
  • Click Generate Worksheet.

Hosting (optional)

  • Sign in () to enable hosted quizzes.
  • After generation, use Host Quiz for All to create links/codes for students.
  • Students open the provided link and submit answers.

Worksheet Marker

Upload one or more worksheet images and generate marks/feedback.

Steps

  • Open Marker.
  • Enter the test name, student name, and marks out of.
  • Upload worksheet images (multiple images supported).
  • Use zoom controls to inspect the image.
  • Click Mark Worksheet to generate results.

Notes Maker

Generate structured notes/slides for a topic and export as PDF.

Steps

  • Open Notes.
  • Fill in all parameters.
  • Click Generate Presentation.
  • Use Download PDF once it's ready.

Account, History, and Sign Out

  • Click in the top bar to sign in/sign up.
  • When signed in, features like history and hosting become available on supported pages.
  • Use Sign Out in the top bar to log out everywhere.

Troubleshooting

  • History doesn't load: Sign in first, then refresh the page and open the history sidebar.
  • Student link not working: Confirm the hosted link is correct.
